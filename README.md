# portfolio

Portfolio site for **Vishwesh Joshi** ([@TheLangdaTyagi](https://github.com/TheLangdaTyagi)): Senior Engineering Manager at BMO and Founder of OP Techies Limited.

Live at **https://thelangdatyagi.github.io/portfolio/** (GitHub Pages).

A static site with no build step: `index.html`, `styles.css`, `script.js`.

| Path | What it is |
|---|---|
| `assets/shots/chess/` | Chess overlay: 4 scenes × 3 themes (`wood`, `neon`, `minimal`) |
| `assets/shots/stream/` | Touchline Desk: 3 presets (`broadcast`, `aurora`, `bold`) × 4 layouts (`talk`, `solo`, `xi`, `share`) |
| `assets/shots/heldtime/` | heldtime.ca, desktop (top and full page) and mobile |
| `assets/vishwesh-portrait.webp` / `.jpg` | Hero portrait, cropped 4:5 at 880×1100. The full-size original (`assets/vishwesh.jpg`) is git-ignored. |

## Publishing

Settings → Pages → *Deploy from a branch* → `master` / `(root)`. `.nojekyll` makes Pages serve the files as they are.

## Previewing locally

Any static server works, for example `npx serve .`, then open the printed URL.
